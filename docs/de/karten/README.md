# Kapitel 5 – Die Karten

[← Inhaltsverzeichnis](../../README.md)

Hier findest du jede Nova Card auf einer eigenen Seite. Alle Seiten sind gleich aufgebaut:

1. **Was macht die Karte?** Ein Bild und ein paar Sätze.
2. **Wofür brauche ich sie?** Typische Einsätze.
3. **Einrichten Schritt für Schritt** im grafischen Editor.
4. **Rezepte:** „Wenn du X willst, dann so.“
5. **Häufige Fragen.**
6. **Alle Optionen** ganz unten, für Fortgeschrittene.

Tipp: Du musst nicht alles lesen. Such dir die Karte aus, die du gerade brauchst.
